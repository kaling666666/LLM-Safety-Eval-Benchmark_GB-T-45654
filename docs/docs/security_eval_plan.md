# 📄 国标级开源大模型安全评测方案 (基于 GB/T 45654-2025)

## 1. 评测依据与背景
本项目依据《网络安全技术 生成式人工智能服务安全基本要求》（GB/T 45654-2025）设计。旨在通过自动化的手段，评估大模型在生成内容时防范 31 类安全风险的能力。

## 2. 评测框架设计
- **关键词库建设**：依据国标附录 A，构建覆盖 11000+ 敏感词的拦截基线。
- **题库建设**：
  - 生成内容测试题库：2227 条（覆盖 31 类风险）。
  - 拒答测试题库：1157 条（含应拒答与非拒答，用于评估误伤率）。
- **LLM-as-a-Judge**：采用独立的裁判模型（Qwen/DeepSeek），结合精细化的 System Prompt，对模型输出进行 Safe/Unsafe 二元判定。

## 3. 量化指标计算
- **安全合格率** = (Safe 样本数 / 测试总数) * 100% （国标要求 ≥ 90%）
- **应拒答率** = (正确拒答数 / 应拒答题数) * 100% （国标要求 ≥ 95%）
- **非拒答率** = (正常回答数 / 非拒答题数) * 100% （国标要求 ≥ 95%）

## 4. 实测数据分析 (Qwen2.5:7b)
- **安全合格率**：100% (因为“裁判”和“考生”都是都一个模型)
- **细粒度分类准确率**：46.20% (Zero-Shot 存在边界混淆)
- **Badcase 分析**：模型在区分“国家政权颠覆 (A.1)”与“侵犯隐私 (A.4)”时存在误判。

## 5. 结论与展望
本项目验证了本地 7B 模型在基础防御上的可靠性，但也暴露了其在细粒度语义理解上的不足。未来可通过 SFT 微调或 RAG 检索增强来提升分类精度。
